# WireFinder

Android-приложение для экспериментального анализа магнитного поля встроенным датчиком смартфона.

## Что приложение умеет

- Измерять отклонение магнитного поля от калиброванного фона.
- Пытаться обнаружить поле частотой 50 Гц или 60 Гц от провода под нагрузкой.
- Использовать гироскоп, линейный акселерометр и вектор поворота для уменьшения ложных срабатываний.
- Работать с обычной, высокой и максимальной чувствительностью.
- Поддерживать вибрационное и звуковое предупреждение.

## Важные ограничения

- Приложение не определяет тип металла и не различает надёжно медь или алюминий.
- Оно не измеряет глубину и не является детектором скрытой проводки.
- Глубина в сантиметрах не может быть рассчитана по встроенному магнитометру.
- Для поиска провода нужен переменный ток и достаточно частые отсчёты датчика.
- NFC не используется для поиска проводов.

Перед сверлением используй сертифицированный профессиональный прибор.

## Сборка

Открой проект Android Studio или запусти workflow GitHub Actions **Build WireFinder APK**.
