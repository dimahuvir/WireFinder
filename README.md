# WireFinder 5CM

Android-приложение для экспериментального анализа магнитного поля с помощью встроенного датчика смартфона.

## Возможности

- Измерение магнитного поля в µT.
- Калибровка в текущем месте.
- Отображение отклонения от базового значения.
- История последних 15 измерений.
- Вибрационное предупреждение.
- Проверка наличия магнитометра.
- Проверка наличия NFC.

## Сборка APK

1. Создай репозиторий GitHub.
2. Добавь все файлы проекта.
3. Открой вкладку Actions.
4. Выбери Build WireFinder APK.
5. Нажми Run workflow, если сборка не запустилась автоматически.
6. Дождись завершения сборки.
7. Открой завершённый запуск.
8. Найди раздел Artifacts.
9. Скачай WireFinder5CM-debug.
10. Распакуй архив и найди app-debug.apk.

## Важное ограничение

Приложение использует только встроенный магнитометр.

Оно не является профессиональным детектором проводки, не распознаёт медный кабель и не определяет глубину его залегания.

NFC не используется для поиска проводов.

Не сверли стену на основании показаний приложения. Для проверки скрытой проводки используй профессиональный детектор.
